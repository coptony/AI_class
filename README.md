# AI_class

가천대학교 컴퓨터공학과 **기계학습프로그래밍** 수업의 실습 및 과제를 정리하는 Repository입니다.

## Environment

- Python
- Google Colab
- pandas
- NumPy
- Matplotlib
- Seaborn
- scikit-learn

## Contents

기계학습프로그래밍 수업에서 진행하는 내용을 주차 및 과제별로 정리합니다.

주요 실습 내용은 다음과 같습니다.

- Data Analysis & EDA
- Classification
- Regression
- Machine Learning Algorithms
- Model Evaluation
